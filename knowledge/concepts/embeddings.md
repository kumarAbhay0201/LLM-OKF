# Embeddings

Embeddings represent information as numerical vectors.

For text, embedding models transform text into vectors where semantically
similar content tends to have similar representations.

## Uses

Embeddings are commonly used for:

- Semantic search
- Retrieval
- Clustering
- Recommendation
- Classification
