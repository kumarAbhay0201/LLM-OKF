# Transformer

The Transformer is a neural network architecture that uses attention
mechanisms to process relationships between elements in a sequence.

Transformers became the dominant architecture for modern Large Language
Models.

## Components

Important Transformer components include:

- Attention
- Multi-head attention
- Feed-forward networks
- Positional information
- Layer normalization
